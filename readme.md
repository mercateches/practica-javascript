# JavaScript Fundamentals – Práctica

## Descripción

Este proyecto corresponde a una práctica de fundamentos de JavaScript, cuyo objetivo es aplicar y comprender conceptos básicos del lenguaje mediante diferentes ejercicios.

A través de esta práctica se trabajan variables, funciones, arrays, estructuras condicionales y ciclos de repetición, utilizando `console.log()` para visualizar los resultados en la consola del navegador.

## Ejercicios realizados

### 1. Variables: `let` y `const`
- Declaración de variables utilizando `let` y `const`.
- Diferencias entre valores constantes y variables modificables.
- Almacenamiento de distintos tipos de datos.

### 2. Funciones
- Creación de funciones con parámetros.
- Uso de `return` para devolver resultados.
- Implementación de funciones para generar saludos y calcular el doble de un número.

### 3. Arrays
- Creación e inicialización de arrays.
- Acceso a elementos mediante índices.
- Uso de la propiedad `length`.
- Incorporación de nuevos elementos mediante `push()`.

### 4. Condicionales
- Implementación de estructuras `if / else`.
- Uso del operador ternario.
- Evaluación de condiciones para clasificar calificaciones como aprobadas o desaprobadas.

### 5. Ciclos de repetición
- Recorrido de arrays utilizando un ciclo `for`.
- Recorrido de arrays mediante `forEach()`.
- Acceso e impresión de los elementos de una lista.

### 6. Números aleatorios
- Uso de `Math.random()`.
- Aplicación de `Math.floor()`.
- Generación de índices aleatorios para seleccionar elementos de un array.

## Tecnologías utilizadas

- HTML5
- JavaScript (Vanilla JS)
- Consola del navegador

## Cómo ejecutar el proyecto

1. Clonar o descargar el repositorio.
2. Abrir el archivo `index.html` en el navegador.
3. Abrir las herramientas de desarrollador presionando `F12` o `Ctrl + Shift + J` (Windows) / `Cmd + Option + J` (Mac).
4. Seleccionar la pestaña **Console** para visualizar los resultados de los ejercicios.

## Uso de herramientas de IA

Durante el desarrollo de esta práctica se utilizó Claude como herramienta de apoyo para agilizar la elaboración inicial del código.

Posteriormente, se realizó una revisión detallada de la implementación, verificando la coherencia de las variables, los nombres de funciones, los parámetros, los índices y la correspondencia entre los diferentes ejercicios.

El objetivo fue comprender la lógica aplicada y asegurar que cada ejercicio cumpliera con los requerimientos solicitados.

## Aprendizajes

Esta práctica permitió reforzar los fundamentos de JavaScript y familiarizarse con la sintaxis del lenguaje, la manipulación de arrays, la reutilización de funciones y el control del flujo de ejecución.

También permitió incorporar herramientas de inteligencia artificial como apoyo al proceso de aprendizaje y desarrollo, manteniendo la revisión y comprensión del código como parte fundamental del trabajo.
